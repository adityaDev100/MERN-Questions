1. what is Agile methodology ?

Agile methodology is a way of managing software development that focuses on delivering small, working pieces of the product in short time periods called sprints. Instead of building everything at once, the team works in cycles, gets feedback early, and keeps improving.

It helps teams stay flexible, work closely with the client, and respond quickly to changes.

2. what is CI/CD pipeline

CI/CD pipeline stands for Continuous Integration and Continuous Deployment.
It’s a process that automates the steps of building, testing, and deploying code.

In my understanding, when a developer pushes code to a shared repository, the pipeline automatically runs tests (CI) to check if the code is working properly. If everything passes, the code can be automatically deployed to a staging or production server (CD).

This helps in faster and safer delivery of software with less manual effort.



3. what is SDLC

SDLC stands for Software Development Life Cycle.
It is the process or steps followed to build software from start to finish.
It includes phases like:
Requirement gathering – understanding what the client needs
Design – planning how the software will work
Development – writing the actual code
Testing – checking if everything works correctly
Deployment – releasing it to users
Maintenance – fixing bugs or adding updates after release
It helps ensure that software is built in a structured and efficient way."**
